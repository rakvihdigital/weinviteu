# Design reference

The user supplied https://www.dreamsinvite.com/ as the direction for V2. Its homepage was inspected in web search and the browser. The useful patterns were a warm luxury palette, split hero with mobile showcase, animated invitation entrances, and soundtrack controls.

WeInviteU retains its own name, copy and frontend/editor architecture. This is an original implementation of that general experience, not the reference site's source code, paid template artwork or music. No third-party testimonials, ratings, delivery promises or contact details are reused.

The original procedural 3D scene is editable in src/components/PalaceScene.tsx. The new visual overrides are in src/app/cinematic.css.

## V3 change of direction

The user requested another design and different templates after V2. V3 therefore uses an original editorial-studio homepage instead of the reference-inspired phone hero. Twelve individual compositions replace the repeated arched card. The 3D entrances and audio remain as functional features.
