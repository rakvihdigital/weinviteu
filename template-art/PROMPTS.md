# Image prompts for the story templates

Generate each image in **portrait 9:16** (for example 1080×1920). Use ChatGPT (image), Gemini, or Midjourney (add `--ar 9:16` in Midjourney).

**Rules for every image**
- **No text, letters or logos** in the picture. The invitation text is added by the template.
- **Keep the top third and bottom fifth calm and uncluttered.** Headlines sit at the top and buttons at the bottom.
- **Faces, if any, should be soft, side-on or from behind.** Hands and details work best.
- **Keep the same style within each template.** Paste the *Style* line before every prompt in that template.

**Where to save:** put each image in the folder shown, with the file name shown (`.png`, `.jpg` or `.webp` are all fine). For example: `template-art/wedding-golden-vows/01-opening.png`.
